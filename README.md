A Python notebook (jupyter/google colab) for parsing black-and-white images into a plaintext format, that the PICO ssd1306 protocol can read back and display as a graphic; examples and python version included
Should support everything that PIL supports

This code is explicitly NOT meant to run on the PICO itself, a micropython-like example is included in the notebook/py file, but proper micropy and C readback example files are yet to be added

The image file should be uploaded to the notebook or in the same folder as the .py file.
